# USBAnywhere Mac artwork

App icon generated with the built-in image-generation tool. The menu-bar companion is a deterministic monochrome vector drawing, designed separately for small sizes and marked as a macOS template image. No image API key or CLI fallback was used.

## App icon prompt

Use case: logo-brand.
Asset type: production macOS app icon for USBAnywhere Server, a native utility that forwards physical USB devices to another computer over a network.
Create a single polished, distinctive app icon, straight-on square composition, 1024x1024. One centered rounded-square tile, occupying about 82% of the canvas with transparent space around its rounded corners. Deep indigo to electric-blue enamel background, restrained teal/cyan accents. A bold, immediately legible ivory USB-A plug silhouette flows through one smooth cable curve into a small network junction with two circular endpoints, expressing USB sharing. Strong simple silhouette that reads at 32 pixels; generous breathing room, precise geometry, subtly dimensional materials and very restrained soft highlights. Modern native Mac utility aesthetic. No text, no letters, no watermark, no Apple logo, no desktop mockup, no additional objects, no large glow, no cast shadow beyond the tile. Actual transparent outer background. Deliver only the finished icon, not an icon presentation sheet.

## Assets

- `AppIconMaster.png`: original generated image, with transparent outer background.
- `../build/Artwork/AppIcon.icns`: standard macOS icon set exported from the master at build time.
- `../build/Artwork/MenuBarIconTemplate.pdf`: resolution-independent template mark generated by `make-icons.swift`.
- `MenuBarIcon.svg`: editable vector companion source/reference.

Build with `./build.sh`; icon packaging uses Apple's `sips`, `iconutil`, and AppKit. The menu mark uses alpha only and automatically adopts the menu bar's light/dark appearance. Source artwork is retained in this folder; temporary iconset exports are under ignored `build/`.
